# 官方检查点使用规则

## 基本原则

学生原则上使用本人上一模块输出继续后续任务。当本人结果存在问题并阻断后续模块时，可以在助教正式发布后使用官方检查点。

## 允许使用的情况

- 本人前序模块结果存在问题并阻断后续模块。
- 模块结束后，助教A已正式发布对应官方检查点。
- 使用的检查点能够被下一模块直接读取。

## 禁止事项

- 不得在助教发布前自行获取助教参考包。
- 不得将官方检查点作为本人前序模块成果提交。
- 不得修改官方检查点后声称为本人生成。
- 使用检查点时必须在README中记录原因和文件名。

## 发布口径

官方检查点由助教A统一发布，模块主责助教确认内容。任何个人发送的不同版本均不作为正式检查点。
