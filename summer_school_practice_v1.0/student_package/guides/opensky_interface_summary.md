# OpenSky 状态向量课程摘要

OpenSky 在本实践中只作为公开航空状态数据来源，不是课程目标。课堂全部使用 `data/raw_states.json`，不访问实时 API。

## 文件结构

顶层对象包含批次时间 `time` 和状态数组 `states`。`states` 中的每个元素仍是按固定索引排列的数组，不是当前态势表，也不是 TeachingLink 帧。

课程使用索引见 `schema/opensky_field_dictionary.csv`。重点字段包括目标标识、呼号、位置/最近联系时间、经纬度、气压/几何高度、地面状态、速度、航向和垂直速度。

## 必需与可空

- 生成正常教学帧必须有：六位十六进制 `icao24`、可用时间（优先 `time_position`，否则 `last_contact`）和布尔型 `on_ground`。
- 呼号、经纬度、高度、速度、航向和垂直速度允许为空。
- 气压高度优先；为空时可回退到几何高度，并记录高度来源。
- 缺失不能用数值 0 代替；真实 0 值必须保留为有效数据。

## 系统角色

OpenSky 数组进入发送方后，先转换为内部结构化字段，再按学校定义的 41 字节 TeachingLink 格式封装。接收方解封和验证后得到另一份内部记录，随后才能进行 CSV/SQLite、航迹、语义映射和一致性处理。

## 边界

本期不做 ADS-B/Mode-S 信号解码、实时网络访问、重传或协议状态机。OpenSky 字段也不能用于推断真实装备协议。
